# Output

I report Excel generati da `python3 main.py` vengono salvati qui.

```
output/
├── nielsen_gedi_YYYYMMDD_HHMM.xlsx       ← siti interni GEDI
└── nielsen_manzoni_YYYYMMDD_HHMM.xlsx    ← editori terzi Manzoni
```

I file Excel sono ignorati da git — questa cartella serve solo come destinazione locale.
